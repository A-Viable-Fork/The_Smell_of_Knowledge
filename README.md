# The Smell of Knowledge: Attenuating Variety in the Age of AI

Working paper, version 1.5 (April 2026), by A Viable Fork.

AI generation is outpacing mathematics' verification infrastructure. The paper diagnoses the bottleneck as a requisite-variety failure (Ashby, 1956) and proposes an architecture that relocates it across existing institutions: proposers formalize and submit under honestly declared axioms, repositories organize and map the verified record into a theory atlas, and journals curate for their readership.
